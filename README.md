# 🎩 수리수리 마술모자

마술모자 속 토끼 **퐁이**와 함께 마술의 비밀을 배우고, 가족에게 깜짝 마술을 보여 주는 7살 어린이용 마술 게임이에요.
`index.html` 파일 하나로 돼 있어서 브라우저에서 바로 열 수 있어요. 👉 https://toyoungeun.github.io/magic-school/

## 지도
| 마을 | 마술 |
|---|---|
| 🏡 비밀 열쇠 마을 (원리) | 언제나 같은 답 · 말 바꾸기 요술 · 짝꿍 카드 · 눈 돌리기 |
| 🌟 반짝 별 숲 (초급) | 마음속 사탕 마술 · 주사위 밑면 맞히기 · 크레용 투시 |
| ☁️ 뭉게 구름 성 (중급) | 짝꿍 카드 마술 · 과일 예언 · 마법 숫자 카드(1~7) |
| 🐉 용의 탑 (고급) | 세 줄 카드 마술 · 큰 숫자 카드(1~15) · 주사위 탑 투시 |
| 🎪 깜짝 무대 (실전) | 대사 연습 → 화면 마술로 공연 → 관객 반응 기록 |

- 수업은 **구경하기 → 비밀(그림 카드로 한 장씩) → 그림 퀴즈** 순서예요.
- 모든 말풍선은 **소리로 읽어 줘요** (끄기 가능).
- 수업을 끝내면 스티커를 받고, 스티커가 모이면 **마법 알이 용으로 자라요**.
- 그림은 모두 SVG로 직접 그렸어요 (퐁이, 마술모자, 트럼프 카드, 과일, 주사위, 크레용, 마법 알 등).
