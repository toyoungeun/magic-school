# 🎩 주원이의 마술 학교

마술의 원리를 배우고, 응용 마술을 익히고, 실전 무대에서 직접 공연해 보는 어린이용 마술 게임이에요.
`index.html` 파일 하나로 돼 있어서 브라우저에서 바로 열 수 있어요.

## 구성
- **기초 · 마술의 원리**: 계산 속 비밀, 고르게 만들기(포스), 열쇠 찾기, 숨은 정보, 시선과 연기
- **초급**: 마법의 숫자, 주사위 투시, 숫자 카드 마술
- **중급**: 21장 카드 마술, 열쇠 카드 마술, 수정구슬
- **고급**: 1089 예언, 마술사의 선택, 달력 번개 계산
- **실전 무대**: 준비물·대본 연습, 화면을 마술 도구로 쓰는 공연 모드, 공연 기록

각 수업은 체험 → 비밀 배우기 → 퀴즈 순서로 진행되고, 앞 단계를 끝내면 다음 단계가 열려요.
